# AppForge 用户手册（v1.0）

> AppForge 造物台：**你说要什么软件，AI 现场写出来，永久留在桌面，双击秒开。**

---

## 1. 安装与启动

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **绿色便携包（推荐）** | 解压 `dist\AppForge-portable.zip` 到任意目录 → 双击 `AppForge.exe` | 最稳：不涉及自解压、不追加数据，杀毒软件/SmartScreen 误判概率最低 |
| 单文件 | 拷走 `dist\AppForge.exe` → 双击 | 一个文件最方便；首次运行会把内部文件解压到可写目录（约 1 秒） |
| 开发/源码 | 双击 `启动AppForge.cmd` 或 `src\AppForge.Host\bin\Release\AppForge.exe` | 自动按需构建 |
| 桌面常驻 | 双击 `创建桌面快捷方式.cmd` 一次 | 之后从桌面「AppForge 造物台」启动 |

### 1.1 第一次运行可能看到 SmartScreen

因为程序**没有购买代码签名证书**，Windows 可能提示：

> Microsoft Defender SmartScreen 阻止了无法识别的应用启动

处理方式（二选一）：

1. 点 **更多信息** → **仍要运行**（只需一次，之后同一文件不再提示）
2. 或在 PowerShell 里执行一次解除锁定：
   ```powershell
   Unblock-File .\AppForge.exe
   ```

> 这是所有未签名程序的通用提示，不代表程序有问题。若你想彻底避免，可改用**绿色便携包**，或后续由开发者购买证书签名。

### 1.2 受限环境说明（重要）

如果系统策略、杀毒软件"受控文件夹访问"或沙箱限制了某些目录写入，程序会**自动换地方**而不是直接失败：

- 内部文件解压目录：`%LOCALAPPDATA%\AppForge\payload` → `%TEMP%\AppForge\payload` → exe 同目录
- 数据目录：`%LOCALAPPDATA%\AppForge` → exe 同目录 `data` → `%TEMP%\AppForge\data`

如果三处都不可写，启动器会报错并提示用环境变量 `APPFORGE_PAYLOAD_DIR` 指定一个可写目录。
排查记录在：exe 同目录 `logs\launcher.log`、或 `%TEMP%\AppForge\launcher.log`。

**首次启动**：会自动检查系统组件（.NET Framework 4.8 / WebView2 运行时 / 数据目录）。
Windows 11 自带 WebView2；Windows 10 绝大多数机器随 Edge 已安装。**万一缺少，程序会弹窗一键静默安装**（约 100MB，用户级、免管理员），装完自动重启。

**系统要求**：Windows 10 22H2（19045）或 Windows 11，x64。

## 2. 第一次使用：配置模型

1. 点右上角 **⚙ 设置**
2. **API 地址**：默认填的是占位示例，请改成你自己的 OpenAI 兼容网关地址（如自建/本地 Ollama）
3. **API Key**：粘贴 → 点 **保存密钥**
   - 密钥用 Windows DPAPI 加密存放在本机 `secrets.dat`，**界面上永远不回显明文**，也不会进日志
4. **模型**：点 **拉取模型列表** → 从下拉框选（推荐支持 function calling 的模型，如 `gpt-4o-mini`；要更快可用 `gpt-4.1-mini`）
5. 点 **测试连接** → 应显示"连接成功 · xxx ms · 模型名 + 回复"

---

## 3. 造一个应用（生成）

1. 点右上角 **＋ 新建应用**
2. 用一句话描述需求，例如：
   > 做一个待办清单，能勾选、能删除、能按优先级排序，数据存在本机，界面简洁一点
3. **Ctrl + Enter** 或点 **开始生成**
4. 观察 5 个阶段实时进度：`理解需求·规划 → 生成代码 → 运行自测 → 自动修复(需要时) → 保存版本`
   - 生成期间可随时 **取消**（草稿会自动清理，不会留下坏应用）
   - 一般 30~120 秒
5. 通过自测后自动保存为 **v0001** 并直接打开应用窗口；桌面多一张卡片

> AI 是用"工具调用"逐个文件写代码（不是吐一段文本让你自己贴），写完会**真的把页面跑起来自测**（检查 JS 报错/白屏/关键节点），失败会把错误回灌给它自己修，最多 3 轮。**自测不通过不会入库。**

---

## 4. 改一个应用（增量修改）

1. 桌面卡片右上角 **⋯ → 🤖 用 AI 修改**
2. 输入要改什么，例如：`把标题改成我的待办，并在顶部加一行显示今天日期`
3. **开始修改** → 它只改相关文件 → 自测通过 → 存为 **v0002**（旧版本保留）

---

## 5. 版本管理

**⋯ → 🕘 版本历史（vN）**

- 每个版本显示：版本号、备注（AI 生成/修改 + 你的原话）、时间、大小、模型
- **对比**：看某个旧版本与当前版本的文件级差异（新增/删除/修改 + 增删行数 + 变更预览）
- **回滚**：切回旧版本（当前版本不删除，可随时再切回来）
- **打开**：直接打开当前版本

> 保留策略：每个应用默认保留最近 10 个版本（设置页可改），当前版本永不自动清理。

## 6. 带走 / 分享 / 快捷方式

| 想做 | 操作 |
| --- | --- |
| 备份或发给别人 | 卡片 ⋯ → **📦 导出 zip** → 去 `数据目录\exports\` 取压缩包（含源码 + `如何运行.md`，解压后双击 html 浏览器即可用） |
| 桌面一键启动该应用 | 卡片 ⋯ → **🔗 创建桌面快捷方式** → 桌面出现以应用名命名的图标，双击**直接进应用**（不显示造物台） |
| 打开应用文件夹 | 卡片 ⋯ → **🗂 打开目录** |

## 7. 系统集成

设置页 → **🖥 系统集成**：

- **开机自动启动**：登录后自动打开 AppForge（写当前用户注册表 Run 项，可随时关闭）
- **全局快捷键 `Ctrl + Alt + Space`**：任何时候唤出 / 隐藏造物台（被其他软件占用时会提示失败）

**关闭窗口 = 最小化到托盘**（进程继续运行，这是设计行为，方便随时用快捷键唤出）。
之后**再次双击 exe / 桌面快捷方式，会把已有窗口唤回**（不会开第二个进程）；要真正退出请用托盘右键 → 退出。
（v1.0.2 修复了"隐藏到托盘后第二次双击没反应"的问题。）

其他：
- 关闭主窗口 = 最小化到**托盘**（双击托盘图标恢复）；托盘右键可退出
- 重复双击 exe 不会开第二个进程，只会把已有窗口提到前台

## 8. 删除与恢复

- 卡片 ⋯ → **🗑 删除应用** → 移入**回收站**（不是立刻删）
- 设置页 → **🧹 回收站** → 可**恢复**；超过 7 天自动清理

## 9. 数据在哪、怎么备份

| 内容 | 位置 |
| --- | --- |
| 应用源码 / 版本快照 | `%LOCALAPPDATA%\AppForge\data\apps\<appId>\versions\vNNNN\` |
| 索引与设置 | `%LOCALAPPDATA%\AppForge\data\index.json` / `settings.json` |
| 加密密钥 | `%LOCALAPPDATA%\AppForge\data\secrets.dat`（DPAPI，仅当前 Windows 用户可解密） |
| 日志 | `%LOCALAPPDATA%\AppForge\logs\` |
| 导出 / 诊断包 | `%LOCALAPPDATA%\AppForge\exports\` |

设置页 → **🗂 数据目录** → 「打开数据目录」可直接打开。
**备份**：整目录拷走即可（`secrets.dat` 换电脑需要重新填 Key）。
**卸载**：删除程序文件 + 删除 `%LOCALAPPDATA%\AppForge` 即可，不写系统目录、不需要卸载程序（开机自启项请先在设置里关闭）。

## 10. 排障

1. 设置页 → **🩺 诊断** → **导出诊断包**（含 info/配置/日志/依赖状态/应用清单，不含密钥明文）
2. 也可以直接看日志：`%LOCALAPPDATA%\AppForge\logs\app-YYYYMMDD.log`（界面里的 JS 报错也会记进去）
3. 常见情况：
   - **界面空白/白屏** → 多为 WebView2 运行时异常，看日志里的 `Shell 初始化失败`
   - **点开始生成没反应** → 检查设置页 API Key 是否已保存、模型是否可用（点「测试连接」）
   - **提示"已有生成任务在进行中"** → 等当前任务结束或点「取消」
   - **应用打不开** → 卡片 ⋯ → 版本历史 → 回滚到上一个版本
   - **快捷键无效** → 可能被其他软件占用，设置页里关闭再开启会重新注册

## 11. 命令行（可选，排障/自动化）

```powershell
AppForge.exe                      # 正常启动
AppForge.exe --check              # 依赖自检（JSON）
AppForge.exe --selftest           # 无界面自检（59 条断言）
AppForge.exe --bench              # 启动分阶段耗时（JSON）
AppForge.exe --gen="<需求>"        # 无界面跑一次完整生成
AppForge.exe --gen="<需求>" --app=<appId>   # 无界面增量修改
AppForge.exe --ui-diag            # 界面自检（截图 + JS 错误采集，需桌面会话）
AppForge.exe --set-api-key=<key>  # 写入 Key（DPAPI 加密，自动化用）
AppForge.exe --data-dir=<路径>    # 指定数据目录（便携模式）
```
