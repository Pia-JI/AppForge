## 2. 里程碑与验收标准

**交付物**：`README.md`、`docs/01`~`docs/04`。
**验收**：
- [x] 需求 FR/NFR 有优先级与验收口径
- [x] 架构含：选型结论、窗口/进程模型、RPC 契约、数据模型、生成引擎、秒开策略、安全模型、目录结构

- [ ] 用户确认剩余决策点（§7）

### M1 · 宿主 + 依赖自检 + 启动桌面（D2–D6）· ✅ 代码完成

> 实现与验证细节见 [05 M1 实现与验证](05-M1-实现与验证.md)。本节保留原始验收口径，供桌面验收时逐条对照。

**目标**：双击 `AppForge.exe`，≤1.5s 看到桌面；有 3 张示例卡片；点开能弹出应用窗口并显示静态页。
**交付物**：
- 解决方案骨架：`AppForge.Host`（net48 WinForms）/ `AppForge.Shared` / `AppForge.Tests`、`scripts/build.ps1`
- `Bootstrap/StartupChecks`：OS / .NET 4.8（注册表 Release ≥ 528040）/ WebView2（`GetAvailableBrowserVersionString`）/ 数据目录可写
- `Bootstrap/WebView2Installer`：缺失时原生小窗引导 + 内嵌 `MicrosoftEdgeWebview2Setup.exe /silent /install` + 失败兜底
- `Web/ResourceServer`（虚拟主机 → 嵌入资源/版本目录，MIME + CSP + PathGuard）
- `Web/RpcDispatcher`（方法白名单 + 信封 + 来源校验）+ `rpc.js`
- `Data/JsonStore` + `AppRepository`（原子写、`index.json` 重建、3 个示例应用种子）
- `Windows/ShellForm`（单实例、托盘占位、`--open-app` 参数解析、窗口位置记忆）
- `Windows/AppForm`（基础版：导航 + 关闭销毁）
- Launcher UI：卡片墙、空状态、骨架屏、新建按钮（占位）
- `--bench` 启动打点

**验收（🖥 桌面会话）**：
1. 🖥 `dotnet build` 一键构建，产物 exe 双击可用，无任何安装步骤。
2. 🖥 冷启动到卡片可见实测 ≤1.5s（10 次）；`--bench` 输出 JSON。
3. 🖥 卡片点击 → 应用窗口出现且页面正常渲染（无白屏）；关闭后进程不残留。
4. 🖥 重复双击 exe 只有一个进程，第二次仅唤出窗口。
5. 🖥 删掉示例数据目录后启动 → 不崩、自动重建索引/空状态。
6. 逻辑层单测（PathGuard、ManifestValidator、JsonStore 原子写与重建）全绿。
7. **模拟依赖缺失**：强制把 WebView2 检测结果置空 → 走引导页（不闪退、有明确提示与"安装/离线/退出"三选项）。

### M2 · 生成闭环（D7–D14）· 核心里程碑

**目标**：输入"做一个待办清单，能勾选、能删、数据存本地"，**90 秒内**出现可运行应用，并保存进桌面。
**交付物**：
- `Ai/OpenAiCompatible`（`HttpClient` + SSE 手写解析 + tool_calls + 重试 + 取消 + 用量统计）+ `SecretsStore`（DPAPI）+ 设置最简页
- `Policy/SandboxPolicy` + `Policy/AuditLog` + `Policy/PathGuard`
- `Gen/Tools`：`fs.write/read/list`、`web.assert`、`web.screenshot`、`proc.run`
- `Gen/GenerationEngine`（9 状态机 + 事件流 + 取消 + 排队 + run 落库 JSONL）
- `Gen/PromptBuilder`（系统规范 02 §9.4、规划模板、增量模板、修复模板、上下文裁剪）
- `Gen/SelfTester`（隐藏 WebView2 加载草稿：`ConsoleMessage`/`ProcessFailed`/`NavigationCompleted`/`ExecuteScriptAsync` 断言/`CapturePreviewAsync` 截图）
- `Gen/RepairLoop`（≤3 轮）
- `Gen/Finalizer`（manifest 校验 + 版本 v0001 提交）
- Builder UI：输入框、对话流、分步进度、文件树、代码只读
- `fixtures/mock-model/`：6 个固定剧本（成功 / 需修复 / 白屏 / 构建失败 / 取消 / 超时）

**验收**：
1. 🖥 填 Key → 提交需求 → ≤2s 出现流式输出。
2. 🖥 进度步骤对应真实阶段（日志可对上），非假动画。
3. 🖥 生成完成自动弹出预览窗口，页面可用（人工操作 30s 不报错）。
4. 用 mock 剧本"需修复"跑 `--selftest` → 修复循环触发 ≥1 轮并最终成功。
5. 用 mock 剧本"白屏" → 3 轮后失败，给出可读诊断，**桌面不出现**坏应用。
6. 🖥 保存后桌面出现卡片，图标/名称正确；重启后仍在。
7. 断网提交 → 明确报错且不留垃圾草稿（草稿区有清理策略）。

### M3 · 持久化 + 秒开 + 版本（D15–D20）

**目标**：重启软件后应用还在；双击 ≤1.0s 打开；能回滚。
**交付物**：
- `Data/VersionService`：快照、回滚、保留 10 版、回收站（7 天）
- `Windows/AppForm` 完整版：独立 origin（`app-<id>.appforge.local`）、CSP、无 RPC 通道、窗口尺寸按 manifest
- `Runtime/CrashGuard`：`ProcessFailed` / 导航失败 / 白屏 → 兜底页 + "让 AI 修"
- `Windows/PreheatPool`（LRU ≤3 + 内存阈值）+ 图标/缩略图缓存 + 启动延迟初始化
- 增量修改主链路（现有代码进上下文、限定改动文件、提交 v000N）
- `scripts/bench.ps1` + 性能报告

**验收（🖥）**：
1. 杀进程重启 → 列表与打开状态一致，`lastOpenedAt` 排序正确。
2. 双击应用 P50 ≤500ms、P99 ≤1.0s（10 次实测；首次无预热场景另计）。
3. 第二次打开同一应用 → 无构建、无重复初始化（打点证明）。
4. 对应用说"把标题改成我的待办，加一个按日期排序按钮" → 只改相关文件（其余文件字节不变），提交 v0002。
5. 回滚 v0001 → 打开为旧版；切回 v0002 正常。
6. 两个应用同名 `localStorage` key 互不串（origin 隔离验证）。
7. 🖥 应用页面故意死循环/崩溃 → 兜底页出现、"让 AI 修"可点、宿主不退出。

### M4 · 完整度补齐（D21–D27）

**目标**：覆盖 01 文档 P0+P1，体验"像个正经软件"。
**交付物**：搜索、置顶/右键菜单/重命名、删除→回收站/恢复、导出 zip、`.lnk` 快捷方式（`--open-app` 直达）、设置页全量（模型多档/工作区迁移/快捷键/开机自启/保留数/连接测试）、**依赖状态页**（`dep.status`：WebView2/.NET 版本与修复入口）、托盘菜单、全局快捷键、诊断面板（人话+技术折叠+复制诊断包）、token/耗时统计、审计查看、危险命令确认。
**验收（🖥）**：
1. 搜索输入即筛 ≤50ms；支持中文与英文。
2. 导出 zip → 解压后 `index.html` 双击可在浏览器打开（存储功能除外）。
3. 生成的快捷方式双击直接进应用且不显示桌面。
4. 工作区从 C 盘迁到 D 盘 → 应用全部可启动，旧目录清理提示。
5. 危险命令（如 `del /s`）触发确认；拒绝后 run 失败并留审计。
6. `Ctrl+Alt+Space` 唤出桌面 ≤100ms。
7. 依赖状态页能正确显示"当前 WebView2 版本 155.x / .NET 4.8.09221"。
8. `tests/regression.md` 中 P0/P1 条目逐条打勾。

### M5 · 打包发布（D28–D31）

**目标**：在**干净 Windows 虚拟机**（Win10 22H2 + Win11）上，拷过去双击就能用。
**交付物**：单文件 `AppForge.exe`（内嵌 wwwroot + 3 个桥 dll）、版本信息与图标、用户手册 1 页、3 个示例应用、`--selftest` 全链路、已知问题、CHANGELOG。
**验收**：
1. 干净机拷贝单 exe → 双击可用；**无需安装、无需管理员**。
2. 单 exe ≤5MB；空闲内存 ≤150MB（无应用窗口）；磁盘占用 ≤15MB。
3. 首启无 Key 时进入体验模式（3 个示例应用可打开、不可生成）。
4. **WebView2 缺失场景演练**（虚拟机停用/卸载运行时）→ 引导页出现 → 在线静默安装成功 → 自动重启可用。
5. `--selftest`（mock 模型）全绿：生成 → 自测 → 保存 → 重启 → 打开 → 回滚。
6. 卸载 = 删目录；不残留进程、不残留注册表（开机自启项显式可关）。
7. Win10 22H2 与 Win11 双机验证通过（高 DPI 125%/150% 不糊）。
