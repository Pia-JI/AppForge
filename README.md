# AppForge · 造物台

> 一句话定位：**一个 Windows 启动桌面 —— 你说要什么软件，AI 现场写出来，然后永久留在桌面上，双击秒开。**

导出 zip、桌面快捷方式、回收站恢复、全局快捷键、开机自启、诊断包，**打包为 0.42MB 单文件 exe**。

## 1. 产品要解决什么

| 现状痛点 | AppForge 的做法 |
| --- | --- |
| 通用软件功能臃肿，想要的小工具没人做 | 自然语言描述 → AI 现场生成一个专属小软件 |
| 用 Chat 让 AI 写的代码，聊完就散了，下次要重新生成 | 生成结果沉淀为"应用"，进本地库，永久保留、可反复打开 |
| AI 生成的网页要开浏览器、要跑命令、要装依赖 | 双击即开，宿主内置运行时，应用不需要用户配置环境 |
| 生成的东西不可靠，跑不起来没人管 | 生成→自动运行→自动自测→失败自动修复，跑通才允许保存 |
| 生成的应用打开慢、构建慢 | 生成规范强制"免构建产物"，构建只做一次并缓存，二次打开 0 构建 |

**四条不可妥协的产品红线：**

1. **必须能留住**：应用是本地资产（代码 + 版本 + 元数据），可导出、可迁移、不依赖云端。
2. **必须够快**：壳冷启动 ≤ 1.0s（P50）/ 2.0s（上限），应用双击 ≤ 500ms（P50）/ 1.0s（上限），单页应用生成 ≤ 60s（P50）。
3. **必须真能跑**：交付标准是"用户双击能用的软件"，不是"一段看起来对的代码"。
4. **必须零安装**：**安装型外部依赖 = 0**，只用 Windows 自带组件；万一缺 WebView2，首次打开自动静默装好。免安装绿色包，双击即用、不要管理员。

## 3. 技术基线（已落地）

| 层 | 选型 | 来源 | 状态 |
| --- | --- | --- | --- |
| 宿主运行时 | **C# / .NET Framework 4.8** | Windows 内置 | ✅ |
| 窗口容器 | **WinForms** | .NET Framework 内置 | ✅ |
| 渲染引擎 | **WebView2（Evergreen 运行时）** | Win11 内置；Win10 多数随 Edge 预装（缺失则首启静默装） | ✅ |
| 界面 | **原生 HTML/CSS/JS（ES Modules，零构建、零 node_modules）** | 内嵌进 exe | ✅ |
| 数据 | **文件系统 JSON + 原子写 + 每日快照**（接口预留 SQLite） | BCL | ✅ |
| AI | OpenAI 兼容协议（默认网关 `https://api.example.com/v1`，默认模型 `gpt-4o-mini`） | `HttpClient` + 手写协议 | ✅ 连通性已验证 |
| 密钥 | **DPAPI**（`ProtectedData`，CurrentUser），磁盘无明文 | BCL | ✅ |
| 打包 | 便携包 `dist\AppForge-portable.zip`（0.43MB）+ 单文件 `dist\AppForge.exe`（0.45MB） | 无安装器 | ✅ |
| 唯一第三方代码 | WebView2 托管桥 3 个 dll（≈0.8MB，随包内嵌，无需安装） | 内嵌 | ✅ |

> ⚠️ **为什么不用 Electron**：它会把 Chromium + Node 整包塞进安装包（150MB+），与"优先用 Windows 自带"直接冲突。详见 02 §2 与 04 依赖预算。
> 当前 Release 输出目录合计 **1.25 MB**。

## 5. 快速开始

**方式一：绿色便携包（推荐，解压即用）**

```powershell
.\scripts\pack-portable.ps1     # 产出 dist\AppForge-portable.zip（约 0.43MB）
```
解压到任意目录 → 双击 `AppForge.exe`。不含自解压逻辑，杀软 / SmartScreen 误判概率最低。

**方式二：单文件（拷走一个文件）**

```powershell
.\scripts\pack.ps1              # 产出 dist\AppForge.exe（约 0.45MB）
```
双击即可；首次运行会在**内存中**解压内部文件到可写目录（自动在 `%LOCALAPPDATA%` / `%TEMP%` / exe 同目录中择一，约 1 秒），不依赖 TEMP。
> 未购买代码签名证书，Windows 可能提示 SmartScreen：点「更多信息 → 仍要运行」，或先执行 `Unblock-File .\AppForge.exe`。

**方式三：双击脚本（开发/绿色目录）**

| 入口 | 作用 |
| --- | --- |
| **`启动AppForge.cmd`** | **双击启动（推荐）**：自动判断是否需要增量构建 → 启动 AppForge；失败会暂停并显示原因 |
| **`创建桌面快捷方式.cmd`** | 双击一次：在桌面生成「AppForge 造物台」快捷方式（以后真正一键，不弹控制台） |
| `src\AppForge.Host\bin\Release\AppForge.exe` | 已构建时最快：直接双击裸 exe |

启动脚本支持的参数（可选，双击时默认不需要）：

```powershell
.\启动AppForge.cmd                 # 按需构建 + 启动
.\启动AppForge.cmd -NoBuild        # 只启动，不检查构建
.\启动AppForge.cmd -DryRun         # 演练：只打印将要做什么
.\启动AppForge.cmd -DataDir D:\af  # 指定数据目录（默认 %LOCALAPPDATA%\AppForge）
.\启动AppForge.cmd -OpenApp apdemo0001   # 启动后直接打开某个应用
```

首次启动后：桌面有 3 个示例应用（待办清单 / 番茄钟 / 单位换算）→ 点 ⚙ 进入设置：
API 地址已预填，**粘贴一次 API Key → 保存密钥 → 拉取模型列表 → 测试连接**。

配好之后：点右上角 **「＋ 新建应用」** → 用一句话描述需求 → **开始生成**（30~120 秒，可 Ctrl+Enter 提交）
→ 它会自动写代码、跑自测、必要时自我修复，通过后保存到桌面并直接打开。

**想改已有的应用**：卡片右上角 **⋯ → 🤖 用 AI 修改** → 说"把字体调大 / 加一个按日期排序的按钮"
→ 只改相关文件，自测通过后存为**新版本**（v0002…），随时可在 **⋯ → 🕘 版本历史** 里回滚或对比。

**带走/备份**：**⋯ → 📦 导出 zip**；**⋯ → 🔗 创建桌面快捷方式** 之后双击桌面图标直接进应用。
**其他**：设置页可开 **开机自启 / 全局快捷键 Ctrl+Alt+Space**，删除的应用在 **回收站** 可恢复，遇到问题可 **导出诊断包**。
（密钥用 DPAPI 加密保存在本机，`secrets.dat` 中无明文；代码与文档里不包含任何密钥。）

诊断：`.\scripts\ci.ps1`（构建 + 42 条自检 + UI 静态检查 + 启动基准）。

## 6. 已确认的决策

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 技术栈 | ✅ C# + WinForms + WebView2（"Windows 自带优先"的唯一解） |
| D2 | 应用形态 | ✅ v1 只做 Web 类（HTML/JS），Node 脚本放 P1 |
| D3 | AI 供应商 | ✅ 默认 `https://api.example.com/v1` + `gpt-4o-mini`，可在设置页改任意兼容网关/模型（含本地 Ollama） |
| D4 | 界面技术 | ✅ 原生 HTML/JS，无构建 |
| D5 | 交付形态 | 单文件 exe 优先（M5），绿色目录版作为兜底 |

> GUI 验收提示：WebView2 需要命名管道与桌面会话，**必须在真实桌面双击运行**；受限沙箱里只能跑逻辑层自检（`--selftest`）。
